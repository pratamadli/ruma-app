# RUMA — Documentation Governance

Documentation is a first-class engineering artifact.

## Update Matrix

| Change                | Update                            |
| --------------------- | --------------------------------- |
| Product behavior      | PRD + module docs                 |
| Roadmap               | ROADMAP                           |
| Database/schema       | `DATABASE.md` + migration         |
| API                   | `API_ARCHITECTURE.md` / contracts |
| Architecture          | ADR + `ARCHITECTURE.md`           |
| Domain boundaries     | `DOMAIN_MODEL.md`                 |
| Frontend architecture | `FRONTEND_ARCHITECTURE.md`        |
| UI system             | `UI_GUIDELINES` + design tokens   |
| AI behavior           | `AI_GUIDELINES`                   |
| Security              | `SECURITY.md`                     |
| Testing               | `TESTING_STRATEGY.md`             |
| Workflow / CI         | `DEVELOPMENT_WORKFLOW.md`         |
| Observability         | `OBSERVABILITY.md`                |
| Deployment            | deployment/runbook                |

## Definition of Done

A feature is not complete until:

- Code is implemented.
- Tests exist where appropriate.
- Database migrations exist when needed.
- Documentation is updated.
- Architecture impact is resolved.
- Changelog/release notes are updated when appropriate.

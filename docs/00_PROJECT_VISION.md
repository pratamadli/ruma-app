# RUMA — Project Vision

## Vision

Build the operating system for household life.

RUMA is a shared, calm workspace where a family manages coordination, home, money, assets, knowledge, and AI-powered insights.

## North Star

Reduce the cognitive load of running a household.

## Core Principles

- Family-first.
- Automation over manual work.
- AI enhances, never replaces.
- Documentation is part of the product.
- Long-term maintainability beats shortcuts.

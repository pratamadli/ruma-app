# ADR-001: RUMA Premium Modern Family OS Design Direction

## Status

Accepted

## Decision

RUMA will use a hybrid visual language:

- Soft UI Evolution as the primary foundation.
- Minimalism & Swiss for layout, typography, and hierarchy.
- Bento Box Grid selectively for dashboard composition.
- AI-Native UI selectively for AI surfaces.
- Organic Biophilic influence sparingly for warmth.

## Context

RUMA is positioned as a premium, warm, human household operating system. A playful educational style does not match the long-term brand positioning.

## Consequences

The design system must prioritize calmness, hierarchy, whitespace, accessibility, and restrained visual depth. UI generation prompts and component design must follow this direction.

Canonical detail: `docs/07_UI_GUIDELINES.md`.

## Rejected

Claymorphism, Neubrutalism, Gen Z Chaos, Memphis, Y2K, and heavy Glassmorphism as primary styles.
